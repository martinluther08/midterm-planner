# شرح الفصل الثامن: طرق التكامل (Math 102)

صفحة شرح خطوة بخطوة، مبنية على أسئلة الميدات والفاينلات القديمة.

الأقسام: 8.1 إلى 8.4، ومعها الكسور الجزئية والتكاملات المعتلة من أسئلة الفاينل.

في الصفحة:

- خطوة وحدة على الشاشة، ومكتوب فوقها كم دقيقة تاخذ
- مؤقت تركيز 25 دقيقة مع استراحة 5 دقايق
- أسئلة سريعة تصحح لك فورا
- اختبار قصير بوقت في آخر الصفحة

افتح الملف `index.html` في المتصفح، أو من رابط GitHub Pages.
