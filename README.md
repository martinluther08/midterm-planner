# خطة ميدات Fall 2026

جدول مذاكرة الميد (6 ساعات يومياً) لمواد MATH 102 و AI 418 و CS 201 و CS 351 و ENGL 201،
مع تسجيل وقت البداية والنهاية وتحديد الشباتر اللي خلصت. التقدم محفوظ في Firebase ويتحدث مباشرة لكل من يفتح الصفحة،
والتعديل لصاحب الخطة فقط بعد الدخول بحساب Google.

- `index.html` — الموقع كامل (ملف واحد).
- `firestore.rules` — قواعد الحماية: القراءة للجميع، والكتابة لإيميل صاحب الخطة.
